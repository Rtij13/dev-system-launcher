Dev System Launcher

Start here if you want to brainstorm ideas or begin a new isolated project.

Bots

  • StartHere Open this first Front door for brainstorming and exploring ideas (open this first if you don’t have a project yet).
  • ProjectStarterCreates a fresh isolated project when you are ready.
  • DevSupervisorCoordinates the project once it exists.
  • DevCoordinatorHands tasks to the coding tools.
  • ResearchCouncilDoes research and analysis.

Copy-paste prompts

1. Send to StartHere
I want to brainstorm and explore ideas
2. Send to ProjectStarter (replace [name])
Create a new isolated project called [name]
Every project lives in its own folder under /projects/[project-name]/.
